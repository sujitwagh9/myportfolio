## Problem

Spotting unusual values in a time-series dataset by scanning it is slow and unreliable, especially for people who aren't analysts.

## What it does

- **CSV upload** of any time-series dataset.
- **Anomaly detection** using statistical techniques to flag outliers.
- **Interactive visualisation** of the series with anomalies highlighted.
- **Report generation:** an anomaly summary, exportable as CSV.
- **Dark and light mode.**

## Stack

Python · Flask · JavaScript · HTML/CSS

## Outcome

A self-contained web tool that turns a raw CSV into a clear picture of where the data misbehaves.
