## Problem

Git's model of commits, branches and merges is abstract. Beginners memorise commands without a picture of what they do to the repository.

## What it does

- **Simulates core version-control operations:** add, commit, create branch, switch branch and merge.
- **Shows the repository state** after every operation, so you can see branches diverge and merge.
- **Reset** to start again from a clean state.

## Architecture

A Flask backend keeps the simulated repository state and exposes one endpoint per operation. The browser frontend calls them and redraws the state.

## Stack

Python · Flask · JavaScript · HTML/CSS

## Outcome

An educational tool that turns Git commands into something you can see.
