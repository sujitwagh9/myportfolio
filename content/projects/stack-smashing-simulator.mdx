## Problem

Stack-based buffer overflows, such as an unchecked `strcpy` into a 10-byte buffer, are a classic security bug. They're hard to understand from source code alone, because what matters is what happens to the stack.

## What it does

- **Parses C code** to find functions, buffers and calls.
- **Emulates the stack** as the program runs.
- **Detects vulnerabilities** such as unsafe `strcpy` and `gets` calls that can overflow a buffer.
- **Suggests protections** for the vulnerable code.
- **Visualises** the stack so the overflow is easy to see.

## Architecture

Separate Python modules for each stage: parser, emulator, vulnerability detector, protector and visualiser, tied together by a main script.

## Outcome

A teaching tool that makes a low-level security concept visible.
