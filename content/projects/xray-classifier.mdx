## Problem

Chest X-rays can show several different diseases, and a quick first-pass classification helps decide what needs attention first.

## Architecture

- A **CNN** classifies uploaded chest X-ray images across multiple disease classes.
- A **Flask** back end serves predictions in real time.
- Results are shown with **heatmaps** that highlight the regions the model focused on, and can be downloaded as a visual report.

## Stack

Flask · CNN · Python · HTML/CSS

## Outcome

A working web app with image upload, real-time prediction, an intuitive results UI with heatmaps, and downloadable visual reports.
