## Problem

Deploying across many VMs revealed a security gap: Docker Compose files held sensitive details (service credentials, endpoints, integration parameters) that **anyone with VM-level access could read or copy**.

## Approach

- Built a custom encryption mechanism so Compose files stay encrypted on disk and are **decrypted only at runtime** with a secure key.
- Generated a **unique key per deployment**, so environments are isolated and one key can't unlock another.
- Made the workflow itself safe: the key is never passed as a command-line argument. It's read with secure input methods, so it never appears in **shell history, process lists or command logs**.
